安全防护

  • 不要将宝塔后台、数据库工具或无鉴权管理端放进这个通配域名。
  • 共享测试环境时，请在 Cloudflare 配置 Access 访问控制。
  • Token 只授予最小权限；不再使用时立即撤销。
