一键安装并配置

填写 Token 和一个通配测试域名。插件会安装 cloudflared、创建 Tunnel 并绑定通配 DNS。

需要：目标 Zone 的 DNS 编辑与 Zone 读取权限，以及账号的 Cloudflare Tunnel 编辑权限。

支持 *.dev.dashen.wang、*.dashen.wang 等左侧通配格式。配置完成后，在宝塔网站中填写匹配域名即可。

安全防护

开发环境也要设好边界

  • 不要把宝塔后台、数据库管理工具或无鉴权管理端放入通配域名。
  • 需要共享测试环境时，建议在 Cloudflare 配置 Access 访问控制。
  • 收紧服务器入站规则，只保留必要服务；Tunnel 仅需要向外建立连接。
  • API Token 只授予本应用所需的最小权限，并在不再使用时立即撤销。
